# Landing Page — Pack Pronto da Camisa do Brasil

Landing page estática responsiva pronta para publicar.

## Como visualizar
Abra `index.html` no navegador.

Para melhor funcionamento, rode um servidor local:

```bash
python -m http.server 8000
```

Depois acesse: `http://localhost:8000`

## Configuração importante
No arquivo `script.js`, troque:

```js
const whatsappNumber = '5511999999999';
```

pelo número real com DDI + DDD + número, sem espaços.

## Publicação
Você pode publicar a pasta diretamente em:

- Vercel
- Netlify
- GitHub Pages
- hospedagem cPanel
